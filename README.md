# Michael Zerbinati — Portfolio

Portfolio personale di Michael Zerbinati, pensato per presentare in modo professionale competenze e progetti in:

- Web Development
- IT Support / Technical Support
- Systems & Networking
- Cybersecurity

## Struttura

- `index.html` — contenuto del portfolio
- `style.css` — grafica e responsive design
- `main.js` — animazioni, menu mobile e terminale interattivo
- `Curriculum.pdf` — CV scaricabile
- `robots.txt` — istruzioni base per i crawler
- `.nojekyll` — permette a GitHub Pages di servire direttamente i file statici

## Pubblicazione gratuita con GitHub Pages

1. Crea un account su https://github.com/ se non ne hai già uno.
2. Crea un nuovo repository pubblico chiamato **michaelzerbinati.github.io** (sostituisci il nome solo se il tuo username GitHub è diverso).
3. Carica tutti i file di questa cartella nella root del repository.
4. Apri **Settings → Pages**.
5. In **Build and deployment**, scegli **Deploy from a branch**.
6. Seleziona il branch **main** e la cartella **/(root)**, quindi salva.
7. Dopo la pubblicazione, il sito sarà disponibile all'indirizzo `https://<username>.github.io/`.

### Aggiornamenti

Per modificare il portfolio in futuro:
1. modifica i file in locale;
2. sostituisci/carica i file nel repository;
3. attendi il nuovo deploy di GitHub Pages.

### Cosa personalizzare dopo la pubblicazione

- Collegamento al tuo profilo GitHub nella sezione Contatti.
- Link ai repository dei progetti.
- Eventuali certificati Cisco/Credly una volta completati.
- Eventuale dominio personale (`michaelzerbinati.it`) in un secondo momento.
